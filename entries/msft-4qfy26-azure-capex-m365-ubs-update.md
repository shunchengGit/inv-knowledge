# 微软4Q/FY26财报前瞻：Azure增长强劲，Capex预期上修，M365商业云加速（UBS 7/26）

## 摘要
瑞银（UBS）发布微软（MSFT.O）4Q/FY26（截至2026年6月财季）财报前瞻与渠道调查总结。基于数十位客户与合作伙伴访谈，UBS维持“买入”评级，但战术上临近财报发布持谨慎平衡态度。市场对AI基础设施提供商Capex上升及云增速超预期能力极为敏感。虽然Azure/AWS需求非常健康，且GitHub Copilot改价带来适度拉动，但外部客户算力容量限制及早期Token优化尝试可能限制Azure指引的超预期空间。将FY27 Capex预测由$2340亿调高至$2610亿。M365方面，受益于Copilot/Cowork改进及板块调价，将FY27 M365 Commercial Cloud增速预测上调70bps至16.2%。目标价由$510微调至$480（对应CY27 Non-GAAP PE 21x）。

## 关键要点

- **Azure与算力限制**：Azure需求保持强劲，但受限于第三方客户GPU容量瓶颈及企业早期Token优化，2H26 Azure增速大幅超预期的门槛较高。
- **Capex预测上修**：由于中短期算力需求依然高企及内存价格通胀，将FY27 Capex预测由$2340亿上调至$2610亿（市场投资者心理预期在$2550-2600亿）。
- **M365/Copilot商业化加速**：Copilot体验改善与M365套餐调价形成合力，将FY27 M365商业云收入增速调高70bps至16.2%。
- **估值与情绪边际**：微软股价年内回调21%已部分消化投资者对Capex飙升及AI ROI不确定性的焦虑；当前CY27E PE仅19x (GAAP) / 17x (Non-GAAP)，具备良好安全边际。
- **财务预测**：预测FY26/FY27营收分别达$3,307.68亿与$3,883.82亿（YoY +17.4% / +17.4%），稀释每股收益（UBS）分别为$16.95与$19.26。

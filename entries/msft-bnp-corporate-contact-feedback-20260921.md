## 摘要

BNP Paribas Stefan Slowinski 在微软 FQ1'27 静默期前与 Investor Relations 沟通。核心发现：GPU 租赁定价是近期几乎所有投资者会议的主导话题；微软确认 Azure 正在提价但仅影响续约合同，现有合同 economics 不变，定价收益将渐进体现而非短期跳升；Azure 当前 mid-40s 增长尚未包含定价贡献，主要驱动仍是机队效率提升和产能爬坡。OpenAI 收入分成累计 cap 确认存在（The Information 报道为 $38bn，预计可维持至 FY29 初）。

## 关键要点

1. **GPU 租赁定价成为焦点**：微软表示 GPU 租赁定价问题在近期几乎每次投资者会议中都被提及。微软确认正在 Azure 内提价，但强调不会重访既有合同 economics——定价仅在续约时重置，意味着 Azure 定价收益将渐进 feather in，而非近期 material step-up。

2. **Azure 增长质量 reassuring**：微软重申近期 Azure 强劲表现非定价驱动，机队级效率提升和持续产能爬坡仍是增长最重要驱动。这意味着 Azure 加速至 mid-40s 增长是在尚未看到定价 material impact 的情况下实现的。

3. **38GW 产能目标被否认**：针对 Bloomberg 报道微软计划到 2032 年将产能扩至 38GW，微软否认该数字准确性但拒绝提供更具体目标。关于 SpaceX 产能合作（Nebius CEO 公开评论 + SpaceX 披露新签 ~$1bn/月计算客户），微软拒绝评论具体供应商，但表示持续在 catch-up mode 寻找增量算力，承认当前环境下获取符合规格要求的近期产能困难。

4. **OpenAI 收入分成 cap 确认**：微软确认与 OpenAI 的收入分成累计上限存在，但拒绝披露具体规模，表示该上限在可预见未来不影响业绩。The Information 此前报道 cap 为 $38bn，BNP 估计若 OpenAI 持续追踪其长期收入目标，该 cap 可支持收入分成持续至 FY29 初。

5. **OpenAI 收入分成会计处理**：微软从 OpenAI 获得收入趋势指示，结合 Azure 使用数据三角验证潜在贡献。但强调收入分成近几个季度并非 Azure 超预期来源，若成为 material 驱动会明确披露。此外，此前 reciprocal 收入分成在重谈协议中被取消，该支付此前计入 COGS 而非抵减收入，因此其移除并未贡献近期 Azure 收入增长。

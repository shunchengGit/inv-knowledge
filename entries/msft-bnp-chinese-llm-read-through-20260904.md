## 摘要

BNP Paribas Stefan Slowinski 就 APAC 团队对中国 LLM 生态系统的首次覆盖（MiniMax Outperform、Z.AI Neutral）发布微软映射分析。核心判断：开源模型能力逼近美国前沿模型，推动 token 市场按智能水平分层而非单纯价格竞争；微软作为云平台反而受益于开源模型普及，因为企业不会自建基础设施而是转向 Azure 托管；OpenAI 关系通过五重机制（收入分成、股权、Azure 消费、IP 授权、战略协同）保持稳固。

## 关键要点

1. **中国开源 LLM 加速企业采用**：MiniMax 和 Z.AI 是中国领先 AI 实验室，开源权重模型性能逼近美国前沿模型。企业 increasingly 寻求优化 token 支出，性能差距缩小扩大了低成本替代方案可服务的工作流范围。

2. **Token 市场分层而非趋同**：开源模型推动 token 市场按所需智能水平分层。前沿模型在推理和质量关键任务上继续享有溢价；开源模型在商品化工作流中竞争加剧。前沿实验室可通过自有闭源生态提供全谱系智能（含旧模型访问），在保持前沿溢价的同时参与全曲线竞争。

3. **微软平台变现优势**：传统企业中，微软可通过 Azure 全栈变现——底层算力、模型托管/API、Agent 构建/编排、甚至软件应用组合。开源模型采用 strengthens 这一机会，因为企业部署 GLM 5.3 或 MiniMax M3 时不会自建基础设施，而是直接转向 Azure 托管。

4. **Frontier lab 客户平台 attach 有限**：AI 实验室已自研模型、托管 Agent 甚至应用，云厂商主要变现基础设施，高阶平台服务 attach 机会较少。相比之下，开源模型企业客户为微软提供更广泛的平台变现空间。

5. **OpenAI 关系五重绑定**：微软持续受益于 OpenAI 关系——① 收入分成、② 股权、③ OpenAI 消费 Azure 服务的大客户协议、④ 获取 OpenAI 模型和芯片 IP、⑤ 微软客户在 Azure 上运行 OpenAI 模型的战略协同。

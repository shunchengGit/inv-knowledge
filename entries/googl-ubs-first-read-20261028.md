# 谷歌三季报瑞银首读：广告低预期与芯片销售利润率疑问

## 摘要
瑞银2026年10月28日发布《Alphabet Inc. - Class A — GOOGL 3Q26 First Read》，共13页，是业绩发布后的第一轮信息检查，而非翌日完整版的重复附件。报告认为搜索与视频广告低于共识、云虽超共识却低于瑞银自身预测，形成盈利预测下修风险。云积压订单和全年资本开支在这一发布时点尚无更新，因此“未披露”只能代表首读的信息集，不能写成公司最终未给数据。外售张量处理器已经对收入增长有重要贡献，但云利润率环比大致持平，使瑞银开始质疑高硬件毛利假设；这仍是分析师推断，不是已披露的芯片分项利润率。（第1页）

## 关键要点
- **事实：广告收入低预期。** 自有网站收入746亿美元，对比共识763亿美元、瑞银773亿美元；搜索634亿美元，对比649亿、657亿美元；视频广告112亿美元，对比114亿、116亿美元。共识与瑞银预测必须分列，不能统称市场预期。（第1页）
- **事实与预期差：云并非全面超预期。** 云收入307亿美元，高于共识292亿美元，却明显低于瑞银389亿美元预测。报告同时称芯片外售已是增长的“重要贡献者”，云利润率环比基本持平；收入增长不能直接证明硬件业务享有超额毛利。（第1页）
- **事实：利润承压含非经营扰动。** 合并会计准则营业利润406亿美元，低于共识434亿与瑞银428亿美元；营业利润率32%，低于市场约34%、略高于瑞银约31%。稀释每股收益2.12美元，首读列市场与瑞银均为2.94美元，同时含87亿美元股权证券未实现损失，不能将全部落差归因为广告或云经营恶化。（第1页）
- **事实与未决项：资本开支不及季度预期。** 三季度资本开支514亿美元，对比共识561亿、瑞银582亿美元；全年此前区间为1950亿—2050亿美元，共识2020亿、瑞银2100亿美元。首读写的是“尚未更新”，不是资本开支需求下降或未来支出已确认不变。（第1页）
- **瑞银当时观点：** 评级仍为中性，目标价380美元，参考股价为10月27日320.58美元。首页2026—2028年瑞银调整后每股收益分别为20.59、19.11、13.75美元，属于预测表口径，不等同本季度2.12美元实际值，也不是翌日修订后的预测。（第1页）

## 来源边界与后续验证

首读正式日期与资源文件日期均为2026年10月28日，首页正式题名为“GOOGL 3Q26 First Read”；次日“More Questions than Answers”为19页，补充订单、估值与完整预测，构成同一事件的独立后续产品，不作为两个独立公司证据源。
首读标题段以二季度积压订单5100亿美元作约数，下文则明确列5140亿美元；本条保留约数与精确引述的区别，不擅自统一为新披露值。（第1页）
首读称“云积压未披露”，应与次日披露5610亿美元区分时间层次。首读每股收益比较列瑞银2.94美元，而次日正文回顾瑞银此前预测2.25美元；两份原文不一致，本条不反向改写首读。（两份各第1页及完整版第2页）
“云利润率持平意味着芯片毛利偏低”只是混合业务的方向性推理；若没有软硬件收入、毛利及费用桥接，不能计算出张量处理器独立毛利率。生成式人工智能成本、广告需求、云盈利扩张与竞争仍是原文风险，不能用一个季度判断解决所有问题。（第1—2页）

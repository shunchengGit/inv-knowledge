# 大摩微软大会前瞻：办公智能体、数据平台与算力效率的验证点

## 摘要

摩根士丹利在微软 Ignite 大会前提出几项验证点：算力、企业数据、模型编排与办公应用能否带来可持续的交叉消费。报告参考微软 FY27 第一财季的增长和利润表现，但没有因为大会预期上调盈利预测。判断重点由发布了什么功能移向生产部署、付费消耗和单位资本产出；这是会前研究，不是会后事实。（第1—3页）

## 关键要点

- **财报背景**：报告转述 Azure 固定汇率同比增长48%，较上季加速6个百分点，M365 商业云固定汇率同比增长18%，集团营业利润率约50%；下一季 M365 商业云约19%是管理层指引。（第1—2页）
- **办公变现**：报告看三个渠道：单独购买 Copilot 席位、升级至 E7、智能体按量消耗。Copilot 日活环比约增50%、活跃消耗积分的客户增长超75%是采用指标，不代表同等幅度的收入增长。（第2页）
- **数据与模型联动**：Foundry 收入超过上年三倍，多模型智能体客户同比至五倍；同时使用 Fabric 与 Foundry 的客户由超1.7万升至超1.9万。该行希望看到这些客户从试验走向更广的生产使用。（第2—3页）
- **算力回报与毛利率口径**：Azure 产品效率改善能释放部分可售产能，但 Azure 占比上升仍可能压制微软云整体毛利率。Maia 300 的部署、支持负载与相对成本是会前观察项，报告未认证其经济回报。（第1、3页）
- **预测与估值**：大摩 FY27／FY28／FY29 EPS 为19.86／24.41／30.71美元，首页另列 Refinitiv 一致预期20.03／23.97／29.43美元。报告维持增持和650美元目标价；第4页列约26倍 FY28 EPS，展示倍数与目标价不必精确相乘。（第1、4页）

## 来源边界

- 财报数字为报告转述，产品与盈利推演为会前预期；不能把它当作 Ignite 会后新指引。尤其需要另查付费预算来源、生产端真实支出、推理成本和新增现金资本需求。
